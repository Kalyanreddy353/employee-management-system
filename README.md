# Employee Management System

## Overview
A Full Stack Employee Management System developed using Spring Boot, React.js, MySQL, and REST APIs.

## Features
- Add Employee
- View Employees
- Update Employee
- Delete Employee
- Search Employee
- Employee Count Dashboard
- Email Validation
- Responsive User Interface

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Maven

### Frontend
- React.js
- JavaScript
- Axios
- Bootstrap

### Database
- MySQL

## Project Structure

EmployeeManagementSystem
├── backend/employee-management
└── frontend/employee-management-ui

## How to Run

### Backend

```bash
mvn spring-boot:run
```

Runs on:

```
http://localhost:8080
```

### Frontend

```bash
npm install
npm start
```

Runs on:

```
http://localhost:3000
```
